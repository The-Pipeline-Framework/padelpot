# Contributing

PadelPot is a deliberately small Apache-2.0 demonstration. Keep contributions focused on real padel coordination: clearer interviews, accessible chat interactions, stronger business invariants and reproducible open-weight inference evidence. Avoid booking integrations, public profiles, mobile apps and generic agent infrastructure.

Run `./scripts/test.sh` for the deterministic suite. Run `./scripts/reproduce.sh ollama` (or the default with an OpenRouter key) for the named live scenario. Run `python3 scripts/scenarios.py` on a fresh running real-model app for privacy and incompatibility tests; it replaces fictional business fixtures, so run it before recording the main scenario. Do not assert exact model wording or introduce inference fallback. Follow the pipeline's generated contracts; never edit generated Java.

Use fictional data only. Keep secrets out of code, logs and evidence. Proposed preferences need owner review, prohibited fields stay private, and model output cannot bypass commitment checks. A failing inference is an acceptable application outcome; it is not evidence of a successful live demonstration.

Please describe the behavior changed and the verification performed in a PR. Contributions should be reviewed before merge. This repository is new work for the 2026 Touch Grass demonstration; framework dependencies are credited separately.
